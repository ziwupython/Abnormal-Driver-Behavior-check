# Abnormal-Driver-Behavior-check
基于YOLO的驾驶员异常行为检测系统~Python+YOLOV8算法+目标检测+图像识别+人工智能

## 一、介绍
基于YOLO的驾驶员异常行为检测系统，技术栈如下：
● 前端：Vue3+Element plus
● 后端：Flask框架
● 算法：YOLO
关键技术：YOLO模型、模型训练、目标检测、人工智能、Python
